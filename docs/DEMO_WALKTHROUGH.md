# Playbook demo walkthrough

1. Select a synthetic contact on the dashboard; its record is reserved, not deleted. Opening does not log a call.
2. Explicitly start the DEMO call attempt and record that the driver answered.
3. Use SAY in the dominant center panel. COACH is recruiter-only guidance; NEXT ACTION identifies the branch action. Use arrows for complete text.
4. In Questions, confirm parked/safe status, preferred name, priority, non-negotiables and employment preference. Discovery is not the approved 1099 questionnaire.
5. W-2 immediately enters external handoff readiness without internal questions/company selection. The shipped referral is unconfigured, so dependent controls are blocked. Switching employment preserves factual history.
6. 1099 continues the recovered 14-question guide. Explicit dropdown choices save and advance; confirm typed answers to advance. Use the review selector to edit answered questions. An unknown/flexible answer requires a reason and does not count as confirmed qualification. After all questions are handled, review offers; pending verification still blocks completion. Carrier terms and real submission integration remain unavailable.
7. In right-side FAQ, click a topic, then the driver’s response. Response, Coach and Source modes preserve context and canonical wording. Show in script explicitly previews the scenario; Return to call script restores the call state and FAQ focus. Escape closes the FAQ. References include the six mini-dialogues and research notes.
8. Use S169 for an unknown question. In Notes record exact question, explicit owner, next action, agreed UTC response time, time zone and channel. Unknown fields stay blank. Save the draft; errors remain visible and retriable.
9. Offers are fictional and selections provisional. Missing current verified terms produce a verification fallback, not a sales promise.
10. Stop contact suppresses the synthetic record through the existing store. Finish with an accurate outcome. Driver-reported applying is unverified, and copying/opening a link does not count as an application.
11. Back to profile pauses; Resume and reload preserve saved answers, notes and history. Unsaved notes warn before leaving. Browser acceptance of these controls remains pending due to local runtime failure; see QA.md.
